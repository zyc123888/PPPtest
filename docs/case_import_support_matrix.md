# 用例导入「支持矩阵」声明（Task E7）

> 背景：V2 生成产物与通用导入模型的能力边界此前未显式声明，存在「保存成功但执行时被静默忽略」的风险。本文档声明当前支持/不支持组合，并在导入校验层对不支持项显式报错（含条目定位）。

## 导入链路行为（2026-11-13 起）

- `POST /cases/import` 保持**整批事务**：任何一条失败，整批回滚；错误信息格式为
  `导入失败：第 N 条（CASE_TYPE · 名称）：原因`。
- Pydantic 层校验（字段类型/枚举）仍先于业务校验执行，错误信息含字段定位。

## 支持矩阵

| 用例类型 | 可生成（V2） | 可入库（导入） | 可执行 | 说明 |
|---|---|---|---|---|
| API（普通请求/断言） | ✅ | ✅ | ✅ | method/path/headers/body/assertions/extractors 全支持 |
| API（scenario 步骤） | ✅ | ✅ | ✅ | `steps_json` 优先按 scenario 执行 |
| API（datasets_json 数据驱动） | ✅（V2 产物含） | ❌ 导入模型无此字段 | ❌ | **不支持**：导入会丢失数据集维度；如需数据驱动请用执行时变量或后续专门的 datasets 契约 |
| UI（native 引擎） | ✅ | ✅ | ✅ | steps_json + assertions + expect_text |
| UI（midscene 引擎） | ✅ | ✅ | ✅ | 动作集合受引擎白名单约束（见 Task E8） |
| PERF（固定负载） | — | ✅ | ✅ | concurrency/total_requests/阈值全支持 |

## 明确拒绝的导入组合

- 任何包含 `datasets_json` / `mock_*` 字段的 V2 导出物**不应**直接走 `/cases/import`：这些字段不在 `CaseImportItem` 模型中，导入前请先剥离并单独评估（当前无数据集执行契约）。
- UI 用例 `steps_json` 中含目标引擎不支持的动作时：编辑器与保存校验给出明确错误（Task E8），执行侧不静默回退。

## 待决事项

1. datasets_json 的执行契约（按数据集展开多条 run，或执行时逐条变量替换）需要产品决策后再实现；
2. 导入项与执行器动作集的一致性校验在保存时进行，执行引擎升级后历史用例不自动迁移。
